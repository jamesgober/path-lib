# v1.1.1 - Documentation build fix

`path-lib` 1.1.1 fixed the documentation build on docs.rs. The crate root asked nightly rustdoc for the `doc_auto_cfg` feature, which nightly has since folded into `doc_cfg` and removed, so the docs.rs builds of 1.0.0 and 1.1.0 failed with `E0557`. It now asks for `doc_cfg`. There is no code change: the library behaves exactly as 1.1.0, including `App::ensure_private` and `App::create_private`.

```toml
[dependencies]
path-lib = "1.1"
```
